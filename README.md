# msfs2024authfix
A fix for the sign-in window not appearing in Microsoft Flight Simulator 2024

I tried to install MSFS 2024 a little bit ago but it just wouldn't prompt me with a sign-in window. All services and apps required were installed, and I was stumped. This will let you sign in using a browser.

I really didn't want to spend a while doing this idiotic fix.

## Disclaimer

This script is **NOT** a tool for piracy or any other forms of unbridled shenanigans, it just routes login to your default browser rather than the game's WebView2 due to the WebView's high failure rate.
